# "How RIMI AI works" thumbnails

Each card in the How-it-works section looks for a purpose-made thumbnail here. Until a file
exists the card falls back to a stock fabric photo, so these can be added one at a time.

**Format:** WebP (PNG is fine too if you rename the path in `src/pages/LandingPage.jsx`),
**400 x 300 px**, under ~40 KB. Displayed at 92 x 70 so detail should read at thumbnail size:
one clear subject, no small text.

The point of each image is to *show the tool's output*, not to decorate. Generate them with
the tools themselves — use the same source pattern throughout so the section reads as one story.

| File | Card | What to show |
|---|---|---|
| `inspirations.webp` | Inspirations | A 2x2 grid of four pattern variations generated from one reference. |
| `pattern-extraction.webp` | Pattern Extraction | Split image: source artwork on the left, the isolated motif on white on the right. |
| `make-seamless.webp` | Make Seamless | One tile repeated 3x3 with faint tile borders — visibly no seams. |
| `colorways.webp` | Colorways | The same motif in three palettes as three vertical strips. |
| `mappings-3d.webp` | Mappings & 3D | The pattern on a product mockup — cushion, tote or mug. Output of the Mappings tool. |
| `upscale-vectorize.webp` | Upscale & Vectorize | The motif at three sizes, small to large, all crisp. Or a vector-line rendition. |
| `design-in-minutes.webp` | Design in minutes | A rough sketch or photo beside the finished print it became. |
| `one-project-every-tool.webp` | One project, every tool | A clean crop of the studio showing one project with several tool tabs open. |
| `more-directions.webp` | More directions, faster | Three repeat or scale variations of one motif, side by side. |
| `see-it-on-product.webp` | See it on product first | A garment or home-textile mockup wearing the pattern. |
| `print-ready-output.webp` | Print-ready output | Tiled artwork with a small chip reading e.g. `300 DPI - TIFF`, or the export panel. |
